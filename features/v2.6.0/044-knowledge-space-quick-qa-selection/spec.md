# F044 知识空间已选内容快速问答

## 1. 背景与目标

知识空间文件列表已有勾选能力，但当前勾选状态与底部快速问答互相独立：聚焦或发送问题会清空勾选，问答请求始终使用当前位置范围。该行为无法满足用户“勾选哪些内容，就只针对哪些内容提问”的需求。

本功能把列表勾选、输入框引用展示和后端检索范围统一成同一份状态。

## 2. 范围

### 2.1 本期包含

- 未选择内容时，继续基于当前位置范围提问。
- 选择文件或文件夹后，在输入框上方按一行横向展示引用卡片；超出宽度时横向滚动。
- 文件与文件夹使用统一的“内容”展示，不在输入框中强调类型差异。
- 选中文件时，仅将该文件加入问答范围。
- 选中文件夹时，递归包含其全部下级文档。
- 同时选择多个内容时，问答范围为全部已选内容的并集。
- 已选择标签时，在已选内容范围内继续按标签取交集。
- 发送成功后保留当前引用，支持连续追问。
- 移除最后一个引用、切换当前位置或新建 / 切换会话时清空引用并恢复当前位置范围。

### 2.2 本期不包含

- 不新增选择数量上限或引用数量文案。
- 不修改知识空间列表的批量操作能力。
- 不新增知识文件、文件夹、会话或引用领域对象。
- 不改变 F029 定义的文件可见性过滤和引用溯源权限。
- 不新增 API 路径、数据库表、迁移或错误码。

## 3. 交互与状态

| 状态 | 输入框展示 | 实际问答范围 |
|---|---|---|
| 未选择内容 | 不展示引用卡片；提示“基于当前文件夹提问，输入＃可指定标签回答…” | 当前文件夹；空间根目录沿用当前实现 |
| 已选择内容 | 每项一个等宽卡片，单行横向排列；提示“仅基于已选内容提问，输入＃可指定标签回答…” | 仅已选文件及已选文件夹的全部下级文档 |
| 已选择内容 + 标签 | 保留引用卡片和范围提示，并展示标签 | 已选内容与标签命中文档的交集 |
| 移除最后一个引用 | 引用区域消失，不清空已输入问题 | 恢复当前位置范围 |
| 发送完成 | 引用保持 | 后续追问继续使用当前引用 |
| 新建 / 切换会话或切换位置 | 引用清空 | 恢复新位置的默认范围 |

## 4. 接口契约

`POST /api/v1/knowledge/space/{space_id}/chat/folder` 在原请求体上增加两个可选字段：

```json
{
  "file_ids": [11, 33],
  "folder_ids": [22]
}
```

- 两个字段均未提供：沿用现有 `folder_id` 范围。
- 任一字段已提供：进入显式选择范围；即使数组为空，也不得回退并扩大到当前位置。
- `folder_ids` 由后端递归展开为下级文档 ID。
- 后端继续按 F029 对候选文档执行 `view_file` 双层过滤。
- `tags` 在显式选择范围上继续取交集。

## 5. 技术边界

- 前端唯一选择源仍为 `knowledgeSelectedFilesState`，列表勾选、输入卡片和请求参数不得维护三套状态。
- 服务端必须校验所选文件 / 文件夹与当前知识空间的关系；检索结果继续经过 `KnowledgeFileVisibilityService`。
- 显式空范围必须得到空候选集，不能以“没有有效 ID”为由自动扩大范围。
- 文件夹只贡献下级文档，不把文件夹记录本身送入向量检索。
