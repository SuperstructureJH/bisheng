# 知识空间已选内容快速问答验收用例

**用例版本**：v1.0

**需求依据**：[spec.md](./spec.md)

**测试环境**：`http://192.168.106.114:13100/`

**默认 UI 执行器**：Codex 内置浏览器

| Case ID | 标题 | 优先级 | 执行层级 |
|---|---|---:|---|
| TC-001 | 未选择内容时沿用当前位置范围 | P0 | 浏览器 + API |
| TC-002 | 选择单个文件后展示并提交显式范围 | P0 | 浏览器 + API |
| TC-003 | 混合多选横向展示，文件夹递归展开 | P0 | 浏览器 + API |
| TC-004 | 移除引用与默认态恢复 | P1 | 浏览器 |
| TC-005 | 发送保留引用，新建会话清空引用 | P1 | 浏览器 |
| TC-006 | 标签与已选内容范围取交集 | P1 | API / 代码 |
| TC-007 | 独立环境健康且共享环境未受影响 | P0 | 环境 |

## TC-001 未选择内容时沿用当前位置范围

1. 进入一个包含可问答文档的知识空间文件夹，不勾选任何内容。
2. 查看底部输入框并发送一个问题。
3. 检查请求体。

预期：

- 输入框不展示引用卡片。
- 提示为“基于当前文件夹提问，输入＃可指定标签回答…”。
- 请求不包含 `file_ids` / `folder_ids`，后端沿用 `folder_id` 范围。

## TC-002 选择单个文件后展示并提交显式范围

1. 勾选一个文件。
2. 查看输入框，聚焦后输入并发送问题。
3. 检查发送前后勾选状态与请求体。

预期：

- 输入框上方展示一个固定宽度引用卡片，名称与列表一致。
- 提示变为“仅基于已选内容提问，输入＃可指定标签回答…”。
- 聚焦和发送均不清空引用。
- 请求包含该文件的 `file_ids`，不扩大到未选内容。

## TC-003 混合多选横向展示，文件夹递归展开

1. 勾选至少一个文件夹和三个文件。
2. 查看引用区域并横向滚动。
3. 发送问题并检查请求及后端解析结果。

预期：

- 所有引用卡片保持单行横向排列，不换行；超出宽度时可以横向滚动。
- 文件和文件夹使用同一种卡片样式。
- 请求分别携带 `file_ids` 和 `folder_ids`。
- 后端候选范围包含直接选择的文件与所选文件夹全部下级文档，不包含文件夹记录本身。

## TC-004 移除引用与默认态恢复

1. 勾选两个内容并在输入框中输入未发送问题。
2. 依次点击引用卡片的移除按钮。

预期：

- 每次只移除对应引用并同步取消列表勾选。
- 移除最后一个引用后，引用区域消失并恢复默认提示。
- 已输入问题保持不变。

## TC-005 发送保留引用，新建会话清空引用

1. 勾选内容并发送问题。
2. 回答结束后继续输入第二个问题。
3. 点击新建会话；再切换到历史会话。

预期：

- 第一条发送完成后引用保留，第二条仍使用同一显式范围。
- 新建会话和切换历史会话均清空引用并恢复默认范围。

## TC-006 标签与已选内容范围取交集

1. 选择一组内容，再通过 `#` 选择一个标签。
2. 发送问题并检查候选文件 ID。

预期：

- 引用卡片、标签和已选范围提示同时存在。
- 后端候选文件为已选内容与标签命中文档的交集。
- 不从未选内容中补充标签命中文档。

## TC-007 独立环境健康且共享环境未受影响

1. 只读探测 `13100` 根入口和 `/api/v1/env`。
2. 查看 `codex-bisheng` 前后端及依赖容器状态。
3. 只读探测 `13000` 与 `3001`。

预期：

- `13100` 根入口和 API 正常，独立环境前后端已重启并运行候选提交。
- OpenFGA 等依赖正常。
- `13000` 与 `3001` 保持可用，部署过程不写入 `/opt/bisheng`。
