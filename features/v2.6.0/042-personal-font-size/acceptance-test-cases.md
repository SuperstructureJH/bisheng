## 核心执行规则

- 第一轮先完整执行所有独立用例，记录 PASS / FAIL / BLOCKED / NOT_RUN，再修改代码。
- TC-003 需同时读取根节点 `--bisheng-display-zoom` 与页面元素尺寸，不能只看选中态。
- TC-006 使用仓库默认 `fontSizeVariant=disabled` 构建验证；13100 使用 `cofco` 覆盖，两者证据不得混用。
- TC-011 至少覆盖工作台首页、知识空间、对话输入区、管理后台模型管理页、个人菜单和一个弹窗/下拉层。
- TC-012 检查遮挡、截断、重叠、横向溢出和控件可点击性；页面可滚动不能代替布局正确。

## 用例明细

### TC-001 / TC-002 中粮双入口

- **前置条件**：`fontSizeVariant=cofco`，电脑端已登录。
- **预期**：两端个人菜单均有【字体大小】，只展示【小 / 标准 / 大】并显示当前勾选；无滑杆、刻度、百分比或操作说明。

### TC-003 三档整页比例

- **步骤**：依次选择小、标准、大，记录根节点比例与文字、图标、头像、Logo、图片、输入框和侧栏尺寸。
- **预期**：比例依次为 0.9、1、1.1；所有对象共同变化，业务内容不变。

### TC-004 / TC-005 偏好与兼容

- **预期**：任一端保存后另一端与刷新后保持一致；历史 1–2 显示小、3–4 显示标准、5–7 显示大。

### TC-006 标品关闭

- **前置条件**：`fontSizeVariant=disabled` 或字段缺省。
- **预期**：两端均无入口；即使账号存在历史大档，根节点无显示缩放属性，页面保持 100%。

### TC-007 保存失败

- **预期**：恢复切换前档位，显示失败提示，不留下错误的本地缓存。

### TC-008 移动端

- **前置条件**：视口宽度小于 768px。
- **预期**：不展示入口，不应用桌面端偏好。

### TC-009 接口边界

- **预期**：未登录更新返回 401；登录后 1/3/5 可保存，0/2/4/6/7/8 返回 422。

### TC-010 二级气泡

- **预期**：工作台向右、管理后台向左；箭头指向菜单项；主菜单高度和菜单顺序不变，关闭主菜单时气泡同时关闭。

### TC-011 / TC-012 页面回归

- **预期**：三个档位下关键页面可操作；固定层、Portal、下拉框、弹窗、画布和输入区不发生新增遮挡或点击失效；1024px 与 1440px 均无阻断性布局问题。

### TC-013 部署边界

- **预期**：13100 根入口、API 与容器健康；13000 和 3001 只读探测为 200；部署只写入隔离目录。
