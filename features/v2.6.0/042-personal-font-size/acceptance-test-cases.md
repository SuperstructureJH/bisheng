## TC-001 管理后台个人菜单存在字号入口

- **前置条件**：管理员已登录 `13100` 管理后台。
- **步骤**：
  1. 打开右上角个人菜单。
  2. 查看【退出登录】上方的菜单项。
- **预期**：
  - 存在【字体大小】入口。
  - 入口位于【退出登录】上方。
- **证据**：管理后台个人菜单截图。

## TC-002 管理后台标品控件为 7 档滑杆

- **前置条件**：`fontSizeVariant=standard`。
- **步骤**：
  1. 从管理后台个人菜单打开【字体大小】。
  2. 查看控件标题、刻度和端点。
- **预期**：
  - 显示【拖动调整字体大小】。
  - 显示 7 个等距刻度与滑杆。
  - 滑杆下方左侧为【小】、右侧为【大】。
  - 不显示 px、行高、档位数字、即时预览或自动保存说明。
- **证据**：控件展开截图。

## TC-003 管理后台调整并保存账号偏好

- **前置条件**：管理员已登录，当前档位可读取。
- **步骤**：
  1. 记录当前档位与页面文字/图标/行高。
  2. 拖动到另一档位并松开。
  3. 刷新管理后台。
- **预期**：
  - 页面文字、功能图标、容器和导航布局同步响应。
  - 刷新后仍使用最近一次成功保存档位。
  - 保存失败时恢复原档并出现失败提示。
- **证据**：调整前后截图、刷新后截图、偏好接口状态。

## TC-004 工作台个人菜单存在字号入口

- **前置条件**：管理员已登录且可进入工作台。
- **步骤**：
  1. 进入 `/workspace/`。
  2. 打开左下角个人菜单。
- **预期**：
  - 【字体大小】位于【退出登录】上方。
  - 标品入口打开与管理后台相同的 7 档控件。
- **证据**：工作台个人菜单截图。

## TC-005 工作台与管理后台共用同一档位

- **前置条件**：TC-003 已成功保存一个非默认档位。
- **步骤**：
  1. 从管理后台跳转工作台。
  2. 打开工作台【字体大小】。
  3. 返回管理后台并刷新。
- **预期**：
  - 工作台控件显示管理后台刚保存的档位。
  - 返回管理后台后仍显示同一档位，不生成第二份设置。
- **证据**：两个产品面的控件选中态截图。

## TC-006 图片与头像不随字号缩放

- **步骤**：
  1. 分别记录默认档和大字号下的个人头像、Logo 或内容图片尺寸。
- **预期**：上述媒体尺寸保持不变；文字与功能图标按 token 响应。
- **证据**：前后截图或浏览器尺寸读数。

## TC-007 管理后台个人设置不扩项

- **步骤**：
  1. 展开管理后台个人菜单。
- **预期**：
  - 只在现有菜单中新增【字体大小】。
  - 工作台入口、修改密码、退出登录等既有项仍存在。
  - 不新增与本需求无关的个人设置页或菜单项。
- **证据**：完整菜单截图。

## TC-008 未登录更新偏好被拒绝

- **步骤**：
  1. 不携带登录态调用 `PUT /api/v1/user/preferences/font-size`，请求体 `{"level":5}`。
- **预期**：返回 HTTP 401。
- **证据**：接口状态记录。

## TC-009 1024px 大字号布局无整页横向溢出

- **前置条件**：窗口宽度 1024px，字体档位第 7 档。
- **步骤**：
  1. 分别查看管理后台主页面和工作台带二级侧栏页面。
- **预期**：
  - 整页不出现横向滚动。
  - 工作台二级侧栏按规则折叠，并允许再次展开。
- **证据**：两个产品面 1024px 截图。

## TC-010 共享环境未受影响

- **步骤**：
  1. 只读探测 `13000` 与 `3001`。
- **预期**：两个入口继续返回 HTTP 200；部署过程未修改 `/opt/bisheng`。
- **证据**：HTTP 状态与部署命令记录。

## TC-011 管理后台字号控件从左侧独立弹出

- **前置条件**：管理员已登录 `13100` 管理后台，个人主菜单处于展开状态。
- **步骤**：
  1. 记录点击【字体大小】前的个人主菜单高度和菜单项位置。
  2. 点击【字体大小】。
  3. 查看字号控件与个人主菜单的相对位置。
  4. 关闭并重新打开个人主菜单。
- **预期**：
  - 字号控件作为独立二级气泡出现在个人主菜单左侧。
  - 气泡箭头指向【字体大小】菜单项，圆角、阴影和间距与工作台二级气泡一致。
  - 个人主菜单高度、菜单项顺序和【退出登录】位置保持不变。
  - 字号控件不在个人主菜单内部向下展开；关闭主菜单后字号气泡同时关闭。
- **修改前证据**：
  - `test-evidence/run-2/TC-011-admin-inline-expanded-full.png`
  - `test-evidence/run-2/TC-011-admin-inline-expanded-detail.png`
- **修改后证据**：由用户在重新部署的 13100 环境手工确认。
