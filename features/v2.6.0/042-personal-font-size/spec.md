# Feature: 中粮专版显示大小

> 本文只描述需求口径；实现决策见 [design.md](./design.md)。

**关联 PRD**: `knowledge-base/technical-solutions/personal-content-font-size.md`
**优先级**: P1
**所属版本**: 中粮专版（BISHENG 标品不发布）
**依赖**: 现有用户登录、工作台个人菜单与管理后台个人菜单

## 范围边界

- **本次纳入**：
  - 中粮专版电脑端工作台与管理后台的【字体大小】入口。
  - 【小 / 标准 / 大】三个固定档位。
  - 类似浏览器缩放的整页显示比例变化：文字、功能图标、头像、Logo、图片、控件和布局整体同比例变化。
  - 偏好按 BISHENG 账号保存，并在管理后台与工作台共用。
- **本次明确排除**：
  - BISHENG 标品入口与设置能力。
  - 移动端入口。
  - Command +/− 等键盘快捷键。
  - 系统、浏览器或中粮宿主应用字号联动。
  - 七档滑杆、逐类语义字号 token 和逐页面大字号适配。

## 1. 用户故事

作为中粮专版的 BISHENG 电脑端用户，
我希望选择小、标准或大三种显示大小，
以便用较低改造成本统一调整整个界面的可视尺寸。

## 2. 验收标准

- **AC-01** — WHERE `fontSizeVariant=cofco`, WHEN 用户分别打开工作台或管理后台个人菜单, THE SYSTEM SHALL 在两个菜单中均提供【字体大小】入口；工作台从主菜单右侧、管理后台从主菜单左侧弹出独立二级气泡。
- **AC-02** — WHEN 用户打开【字体大小】, THE SYSTEM SHALL 仅展示【小 / 标准 / 大】三项，当前项显示勾选，默认选择【标准】。
- **AC-03** — WHEN 用户选择【小 / 标准 / 大】, THE SYSTEM SHALL 分别按 90% / 100% / 110% 调整当前 BISHENG 页面整体显示比例。
- **AC-04** — WHILE 任一档位生效, THE SYSTEM SHALL 让文字、图标、头像、Logo、内容图片、控件、侧栏和业务布局共同缩放，不再维护各类元素的独立字号映射。
- **AC-05** — WHEN 用户刷新、重新登录或在管理后台与工作台之间切换, THE SYSTEM SHALL 应用该账号最近一次成功保存的档位。
- **AC-06** — IF 保存失败, THEN THE SYSTEM SHALL 恢复切换前档位，并提示“字体大小设置保存失败，请重试”。
- **AC-07** — IF 偏好不存在或读取失败, THEN THE SYSTEM SHALL 使用【标准】；历史 1–7 档按 1–2→小、3–4→标准、5–7→大归并。
- **AC-08** — WHERE `fontSizeVariant` 缺省或为 `disabled`, THE SYSTEM SHALL 不展示【字体大小】入口、不应用历史偏好，并保持页面 100% 显示。
- **AC-09** — WHILE 管理后台提供该入口, THE SYSTEM SHALL 只复用现有个人菜单和二级气泡，不扩展或重做其他个人设置。
- **AC-10** — WHILE 【小】或【大】生效, THE SYSTEM SHALL 仍让 BISHENG 应用壳完整覆盖当前浏览器可视区域；不得在底部或右侧留下由缩放产生的空白，也不得让应用壳超出可视区域。
- **AC-11** — WHILE 任一档位生效, THE SYSTEM SHALL 让全屏页面、固定定位元素和 Portal 弹层使用同一显示比例与同一应用可视边界；遮罩、弹窗和菜单不得只覆盖缩放前或缩放后的局部区域。

## 3. 边界情况

- 三档仅代表 BISHENG 页面内部的显示比例，不读取浏览器缩放值，也不修改浏览器缩放设置。
- 缩放后允许页面按现有响应式规则重排；不得因新增逻辑引入控件遮挡、点击失效、应用壳留白或不可恢复的横向溢出。
- 全屏页面必须继承 BISHENG 应用壳尺寸，不得再次使用未补偿的浏览器视口高度覆盖应用壳。
- 低于 768px 的移动端不展示入口，也不应用该偏好。
