# Feature: 个人字体大小

> 本文只描述需求口径；实现决策见 [design.md](./design.md)。

**关联 PRD**: `knowledge-base/technical-solutions/personal-content-font-size.md`
**优先级**: P1
**所属版本**: v2.6.0
**依赖**: 现有用户登录、工作台个人菜单与管理后台个人菜单

## 范围边界

- **本次纳入**：
  - 工作台与管理后台各自电脑端个人菜单中的字体大小入口。
  - 标品 7 档吸附滑杆；中粮版本小、标准、大三档映射。
  - 语义文字、功能图标、控件容器和必要导航布局联动。
  - 偏好按 BISHENG 账号保存，并在管理端与工作台共用。
- **本次明确排除**：
  - 移动端入口。
  - 系统、浏览器或宿主应用字号联动。
  - 图片、头像、Logo、封面和缩略图缩放。
  - 整页 `transform: scale()`。

## 1. 用户故事

作为 BISHENG 电脑端用户，
我希望按自己的阅读习惯调整界面字体大小，
以便在不改变业务内容和其他用户视图的前提下获得更舒适的显示效果。

## 2. 验收标准

- **AC-01** — WHEN 标品用户分别打开工作台或管理后台个人菜单, THE SYSTEM SHALL 在两个菜单中均提供【字体大小】入口；两个入口打开同一种标题、7 档等距刻度和可吸附滑杆，且不展示 px、行高或档位数字。工作台字号控件从个人主菜单右侧弹出，管理后台字号控件从个人主菜单左侧弹出。
- **AC-02** — WHERE 中粮版本开启, THE SYSTEM SHALL 仅展示小、标准、大三档，并分别映射内部第 1、3、5 档。
- **AC-03** — WHEN 用户选择任意档位, THE SYSTEM SHALL 即时更新语义文字、功能图标、控件容器、一级窄栏和二级侧栏的对应 token。
- **AC-04** — WHEN 用户刷新、重新登录或在管理端与工作台之间切换, THE SYSTEM SHALL 在页面主体渲染前应用该账号最近一次成功保存的档位。
- **AC-05** — IF 保存失败, THEN THE SYSTEM SHALL 恢复切换前档位，并提示“字体大小设置保存失败，请重试”。
- **AC-06** — IF 偏好不存在或读取失败, THEN THE SYSTEM SHALL 使用内部第 3 档，且未设置用户上线前后不发生视觉跳变。
- **AC-07** — WHILE 任意档位生效, THE SYSTEM SHALL 保持头像、Logo、封面、缩略图、文档图片、回答图片、插图和水印原尺寸。
- **AC-08** — WHILE 第 5 至第 7 档在 1024px 窄窗口生效且二级侧栏挤压内容区, THE SYSTEM SHALL 默认折叠二级侧栏，并允许用户再次手动展开。
- **AC-09** — WHILE 管理后台提供【字体大小】入口, THE SYSTEM SHALL 只补齐该入口与复用交互，不新增或重做其他个人设置。
- **AC-10** — WHEN 用户在管理后台打开【字体大小】, THE SYSTEM SHALL 以独立二级气泡承载字号控件，气泡箭头指向【字体大小】菜单项；个人主菜单高度、菜单项顺序和其他菜单项位置不得变化，字号控件不得在主菜单内部向下展开。

## 3. 边界情况

- 偏好值超出 1–7 时按默认第 3 档处理。
- 代码、表格正文和图片说明使用内容正文的 87.5%，且不低于 12px。
- 表格和代码块可局部横向滚动，整页不得出现横向滚动。
- 大字号下按钮组可以换行，但主操作和取消操作不得隐藏。
