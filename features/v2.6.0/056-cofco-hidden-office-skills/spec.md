# Feature: 中粮专版预置 Skill 前端隐藏

> 本文只定义需求与验收口径；实现决策见 [design.md](./design.md)。

**关联 PRD**: 用户确认的《2.7 中粮专版指定预置 Skill 可配置为前端隐藏（P0）》
**优先级**: P0
**所属版本**: v2.6.0 中粮专版
**依赖**: F035-linsight-task-mode

## 范围边界

- **本次纳入**：租户级前端隐藏配置、超级管理员后台配置、业务前台不可发现、任务模式服务端强制注入、停用优先、审计日志、docx/pptx/xlsx 三项中粮配置。
- **本次明确排除**：修改 BISHENG 标品或其他租户默认可见性；在前台展示隐藏 Skill 的技术名称、来源或执行过程；把隐藏等同于停用或删除。

## 1. 用户故事

- 作为全局超级管理员，我希望在当前中粮租户范围内配置 Skill 的【前端隐藏】，以便把预置 Office 能力作为产品内置能力提供。
- 作为业务用户或租户管理员，我不应发现、查看、选择或取消隐藏 Skill，以免暴露底层技术实现。
- 作为任务模式使用者，即使客户端未提交隐藏 Skill，系统仍应启用它，以保证内置能力不因隐藏而失效。

## 2. 验收标准

- **AC-01** — WHERE 当前操作者为全局超级管理员, THE SYSTEM SHALL 在 Skill 管理后台展示并允许修改【前端隐藏】字段。
- **AC-02** — WHERE Skill 已开启【前端隐藏】, THE SYSTEM SHALL 在业务前台的搜索、选择、已选卡片与详情入口中不返回或展示该 Skill。
- **AC-03** — WHEN 任务模式组装模型请求, THE SYSTEM SHALL 合并用户显式选择与当前租户内已启用且前端隐藏的 Skill，去重并由服务端下发。
- **AC-04** — IF 隐藏 Skill 已停用、不属于当前租户或文件不可用, THEN THE SYSTEM SHALL 不把它加入最终可执行集合并记录服务端日志。
- **AC-05** — WHEN 旧客户端或直接 API 请求不携带隐藏 Skill, THE SYSTEM SHALL 仍自动补齐；显式删除其 ID不得使其失效。
- **AC-06** — WHERE 当前操作者不是全局超级管理员, THE SYSTEM SHALL 不返回【前端隐藏】配置，且租户管理员不得通过已知 Skill ID 查询或修改隐藏 Skill。
- **AC-07** — WHEN 全局超级管理员修改【前端隐藏】, THE SYSTEM SHALL 记录操作人、时间、变更前后值、Skill 和租户作用范围。
- **AC-08** — WHERE 中粮租户配置已初始化, THE SYSTEM SHALL 将 docx、pptx、xlsx 三项 Office Skill 设为已启用且前端隐藏，不改变其他租户数据。
- **AC-09** — WHEN 全局超级管理员关闭【前端隐藏】, THE SYSTEM SHALL 恢复该 Skill 的既有前台可见和手动选择规则。

## 3. 边界情况

- 隐藏配置不存在时按 `false` 处理。
- Skill 停用优先于前端隐藏，停用项不得自动注入。
- 同一 Skill 同时被用户提交和系统强制加入时，最终集合只保留一份。
- 页面缓存或旧会话中残留的用户选择不得成为隐藏 Skill 身份的服务端返回来源。
